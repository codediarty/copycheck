GPT킬러 결과 보는 법: AI 판정이 나온 문장 고치는 순서

카피체크 편집팀2026.11.25읽는 데 2분

GPT킬러 결과는 글 전체 판정과 문장별 표시를 함께 봐야 합니다. 판정을 바꾸는 것은 표시된 문장이므로, 표시된 문장에서 AI 말버릇을 덜어 내고 다시 검사하는 순서로 고치는 것이 가장 빠릅니다.
목차
  1. 두 가지를 나눠 보세요
  2. 고치는 순서
  3. 바꾸지 말아야 할 것
  4. 다시 검사할 때 비교할 것

두 가지를 나눠 보세요

첫째는 글 전체에 대한 판정, 둘째는 그 판정을 만든 문장들입니다. 판정만 보고 당황해 글 전체를 다시 쓰면 시간도 들고, 새로 쓴 문장이 또 걸리기 쉽습니다. 어떤 문장 때문에 판정이 나왔는지부터 표시해 두세요.

고치는 순서

  1. 표시된 문장 가운데 가장 긴 문장부터 고칩니다.
  2. 문장 머리의 연결어를 지우고, 앞 문장과 이어지게 다시 씁니다.
  3. 같은 끝맺음이 이어지면 두 문장을 하나로 합칩니다.
  4. 숫자 · 이름 · 인용은 그대로 둡니다.
  5. 고친 문장만 모아 다시 검사합니다.

바꾸지 말아야 할 것

판정을 낮추려다 내용까지 바뀌면 안 됩니다. 실험 결과의 수치, 인용한 문장, 고유한 용어는 그대로 두고 표현과 리듬만 바꾸세요. 카피체크 휴머나이징 엔진도 숫자 · 이름 · 인용을 잠가 두고 바꿉니다.

다시 검사할 때 비교할 것

전후 숫자만 보지 말고, 처음 표시됐던 문장이 풀렸는지 문장 단위로 확인하세요. 카피체크는 휴머나이징 전후를 같은 기준으로 다시 재서 문장마다 바뀐 결과를 보여 줍니다.

자주 묻는 질문

GPT킬러 판정을 꼭 0으로 만들어야 하나요?

제출처가 요구하는 기준선 아래로 내려가면 됩니다. 걸린 문장이 남았는지를 먼저 보세요.

다른 검사기 결과로 고쳐도 되나요?

기준은 서로 달라도 AI 말버릇은 비슷하게 잡힙니다. 문장 단위로 고친 뒤 실제로 낼 곳의 기준으로 다시 확인하는 것이 좋습니다.
